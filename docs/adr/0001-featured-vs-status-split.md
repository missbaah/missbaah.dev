# Split `featured` and `status` into independent, single-purpose flags

The Projects page redesign needed to group projects into "Shipped" / "Still in progress," but the existing `featured` filter (used to curate the homepage preview grid) selects a different, overlapping set of projects than `status === "done"`. Rather than reusing `featured` to drive both pages, we kept the two flags fully independent: `featured` controls only the homepage grid, `status` controls only the Projects page grouping and filtering. Conflating them would have made the homepage curation set hostage to shipping status (or vice versa), and the mismatch between the two sets wasn't obvious until the pages were compared side by side — see `CONTEXT.md`'s "Featured vs Status" entry for the canonical definitions.
