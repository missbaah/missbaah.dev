# Narrow `featured` from a curation set to a singleton spotlight flag

The homepage redesign introduces a large hero card for one spotlighted project, plus a grid of "everything else." We considered keeping `featured` as a multi-project curation set (as ADR 0001 defined it) and taking the first match as the hero, or adding a separate `spotlight` field alongside it. We instead redefined `featured` itself to mean "the one project shown as the hero" — exactly one `true` at a time — because a second overlapping curation flag would duplicate `featured`'s job for no benefit, and the hero format only ever has room for one project anyway. The "Also live" grid is simply every project that isn't the spotlight, regardless of `status` — it is not a `done`-only filter, despite the name.
